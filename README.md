# Aaiza Khalid — Portfolio

Static site. No build step, no dependencies.

## Start

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Or just open `index.html` in a browser.

## Working with Claude Code

`CLAUDE.md` — design tokens, component vocabulary, hard rules. Read automatically.
`CONTEXT.md` — project history, decisions, research findings, open work.

Start with the "Open items" section of CONTEXT.md. The Aviary AI case study is
the highest-value missing piece.

## Deploy

Drag this folder to https://app.netlify.com/drop — or `vercel`.
Deploy the multi-file site, not `aaiza-portfolio-single.html`.
